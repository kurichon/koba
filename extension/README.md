# KoBa unpacked extension

This directory contains the **runtime source** used by Chrome and Brave (`manifest.json` is at this directory's root). It is also the source for the versioned ZIPs on [GitHub Releases](https://github.com/kurichon/koba/releases/latest).

**Using KoBa?** Start with the [main README](../README.md) for installation, review controls, and safe upgrades, or the [User Guide](../docs/USER_GUIDE.md) for troubleshooting.

**Contributing?** See [Development](../docs/DEVELOPMENT.md). Only the files allowlisted by `scripts/build-release.mjs` are included in downloadable extension ZIPs; documentation and test fixtures are not bundled.
