KoBa

ことば、そばに。 · Kotoba no Soba — quiet Japanese vocabulary review beside ChatGPT. Nothing appears automatically.

The key is stored in chrome.storage.local and is never injected into the ChatGPT page.

Behavior

The small neutral button sits beside the left edge of the ChatGPT conversation column. Click it when you want to review. Reviews continue automatically card-by-card after each grade until you click the launcher again, press Esc, or close the popup.

Only one review popup is open across ChatGPT tabs at a time. Clicking the launcher in another tab moves the same shared review session there; changing tabs by itself does nothing.

Updates

Check published GitHub releases and show a quiet notice when a newer version is available.

Enabling checks asks for access to GitHub's release API. Your JPDB API key is never sent to GitHub. Private repositories are not supported by this release checker.

How updates are installed

This unpacked edition checks for releases automatically; installing the new files is manual.

  1. Open the release and download its KoBa_v…zip asset.
  2. Extract the extension files into the same folder you already loaded in Chrome or Brave.
  3. Open the browser's Extensions page and press Reload for KoBa. Refresh any ChatGPT tab that asks you to refresh.

Keeping the same installation preserves its settings and API key. A future Chrome Web Store installation can use the browser's automatic installation of updates.
