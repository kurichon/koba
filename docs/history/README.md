# KoBa historical records

[← Current qualification](../QUALIFICATION.md) · [← Current architecture](../ARCHITECTURE.md)

These files preserve earlier requirements, implementation findings, and release decisions as **historical evidence for regression investigations and disaster recovery**. They are **not** the active installation guide or current release qualification.

- [`QUALIFICATION_v0.3.2.md`](QUALIFICATION_v0.3.2.md) — v0.3.2 reliability audit with later preliminary notes added during subsequent development. Its title, hashes, and statements are snapshots; some publication statements are outdated.
- [`BRANDING_0.3.3.md`](BRANDING_0.3.3.md) — original product-name, licensing, migration and ZIP compatibility decisions before public release was established.

The actively maintained user instructions are in the [root README](../../README.md) and [User Guide](../USER_GUIDE.md). Release history lives in [CHANGELOG.md](../../CHANGELOG.md); current architecture is in [ARCHITECTURE.md](../ARCHITECTURE.md).

These snapshots are left intact rather than silently rewritten to match current code. Source history and GitHub Releases provide additional recovery checkpoints.
